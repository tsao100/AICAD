# 定義平面（DefinedPlane）— 所有定義方式規劃與實作狀態

## 通則
- 平面 = 原點 O + 法向量 N + 面內 X 軸（Y = N × X）。結果顯示為半透明方形，可當草圖平面。
- 每種方式的參數存在 `PlaneDef`（JSON 存檔）；所有方式都有「反向（翻轉法向量）」選項。
- 參照（reference）有三種：
  - **點 PlanePointRef**：座標 (x,y,z)／草圖幾何的點（起點、終點、中點、圓心）／線形里程點（TCL + 里程）
  - **方向 PlaneDirRef**：向量／草圖幾何端點的切線（線、弧、多段線、樣條）／基準軸 X、Y、Z／線形切線（TCL + 里程）
  - **線 PlaneLineRef**：草圖直線／兩點連線
- 參照的草圖或線形改變 → 平面自動重算（監看 Sketch::geometryChanged、TCL::dataChanged、基準平面的形狀變更）。
- 未指定 X 軸時，取「世界 X 在平面上的投影」（法向量接近 X 時改用世界 Y），與標準 XY／XZ／YZ 平面的慣例一致。

## 方式一覽
| # | 方式 | 參數 | 計算 | 狀態 |
|---|---|---|---|---|
| 1 | 從既有平面偏移 | 基準平面、偏移量（可用參數運算式） | O = 基準 O + N·offset，N、X 沿用基準 | ✅（原有） |
| 2 | **取線端點，切線當法向量** | 草圖幾何、起點／終點 | O = 端點，N = 該端點的切線（線：起→終；弧：沿弧行進方向；多段線／樣條：端部線段方向） | ✅ |
| 3 | 一點 + 法向量方向 | 點、方向（向量／切線／軸／線形切線） | O = 點，N = 方向 | ✅ |
| 4 | **三點** | 點 ×3 | O = P1，X = P1→P2，N = X × (P1→P3)（共線報錯） | ✅ |
| 5 | **過一點 + 一線** | 點、線 | O = 線上一點，X = 線方向，N = 線方向 × (線上點→P) | ✅ |
| 6 | 兩線（共面） | 線 ×2 | 相交／共面：N = d1 × d2（檢查共面）；平行：N = d1 × (a1→a2) | ✅ |
| 7 | 繞軸旋轉（角度平面） | 軸（線）、參考平面、角度（度，可用運算式） | O = 軸上一點，N = 參考平面 N 繞軸旋轉 θ（Rodrigues），X = 軸方向 | ✅ |
| 8 | 兩平面的中間／等分平面 | 平面 A、平面 B | 平行：中間平面；不平行：等分平面（反向 = 另一條等分線） | ✅ |
| 9 | 過一點且平行於平面 | 基準平面、點 | O = 點，N、X 沿用基準 | ✅ |
| 10 | **線形里程橫斷面** | 線路、里程 | O = 線形該里程的 3D 點，N = 線形 3D 切線（垂直於線形） | ✅ |
| 11 | 取自實體的平面面（選面） | 3D 視圖點選平面 | O、N 取自該面 | ⏳ 需 3D 視圖面選取，未實作 |
| 12 | 與圓柱／圓錐相切的平面 | 面、角度 | — | ⏳ 未實作 |
| 13 | 沿曲線距離點 + 切線 | 曲線、弧長 | — | ⏳ 以 2（端點）與 10（里程）涵蓋最常用情形 |

## 使用
- 指令 `defplane`（選單 Sketch ▸ Define Plane…）；或 XY／XZ／YZ 項目、定義平面項目右鍵「以此平面…定義新平面」。
- 項目右鍵「編輯平面…」可改任何方式的參數；「在此平面建立草圖」。
- 草圖幾何以「草圖 + 幾何清單」選取（尚無 3D 視圖直接點選）。

## 實作對應
- 模型與求解：`cad/DefinedPlane.h/.cpp`（`PlaneDef`、`PlanePointRef`／`PlaneDirRef`／`PlaneLineRef`、`DefinedPlane::evaluate`）
- 對話框：`ui/DefinePlaneDialog.h/.cpp`（方式下拉 + 各方式頁面；點／方向／線的參照編輯元件；即時預覽法向量／原點／X 軸）
- Document：`createDefinedPlane(PlaneDef, name)`、`updateDefinedPlane(dp, PlaneDef, name)`（舊的偏移介面保留為包裝）
- 存檔：`def` 物件（舊檔只有 baseRef／offsetExpression → 當偏移平面讀入）
- 草圖幾何轉世界座標用 `Sketch::planeToWorld`；線形用 `TrackCenterLine::getXY/Elevation/Azimuth/SlopeForCalc`。
