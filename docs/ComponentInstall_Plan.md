# 3D 組件安裝（ComponentInstall）— 規劃與實作狀態

## 需求
插入一個 `*.aicad`（內容 = 一個 3D 組件 + 該組件所需的空間）。使用者提供該組件沿線形的**多個**安裝里程，
程式**依超高（cant）**把組件定位；**道版 Loft 在「所需空間」處開孔**。

## 關鍵觀察（讀程式碼得到）
- 斷面測站的座標系**不套用 cant 旋轉**；cant 只體現在斷面草圖內的「軌道面直線」（建構線，兩端高度 = abs(cant)/2、abs(cant)）。
  所以「依超高定位」= 把組件放到「該里程的軌道面」上，而軌道面 = 各測站軌道面直線沿里程放樣。
- Chamfer 以 Loft 的角點邊（Generated(vertex) 得到的邊）倒角；Loft 開孔後邊會被切開 → **Chamfer 必須以未開孔的基底實體為準，倒角完成後再開孔**。
- `featureDependencies()` 會讓被依賴者被視為「已被消耗而隱藏」→ ComponentInstall 刻意不宣告相依，改用訊號連動。

## 組件座標系（組件在來源 *.aicad 中的座標）
與斷面草圖放置座標系同一慣例：原點 = 該里程軌道面中心點；+X = 沿軌道面朝右手邊鋼軌；
（第 29 項起改為下方「組件座標系」的新慣例）

## 定位演算法（每個安裝里程 p）
1. 取涵蓋 p 的兩個相鄰測站（同一分段），各自找「受 cant 約束的直線」（`CantLineUtil`，與道版圖同一規則）。
2. 軌道面中心點 A(p) 與傾角方向 D(p)（斷面座標，× scale → m）依里程線性內插。
3. `AlignedProfileArray::frameAt(p)` 取精確放置座標系（含曲線、縱坡；與 rebuild() 同公式）。
4. 組件座標系：原點 = A(p) 的世界座標 + 橫向偏移 × D；X = D；Z = 座標系 Z；Y = Z × X（flip180：X、Z 同時反向）。

## 道版開孔
`ProfileLoftSolid::rebuild()` 與 `ChamferSolid::rebuild()` 結尾呼叫 `ComponentInstall::cutSpaces()`：
挑出文件中所有 ComponentInstall 在該 Loft 里程範圍內、包圍盒相交的「所需空間」（放置後），一次 `BRepAlgoAPI_Cut`。
布林失敗 → 維持未開孔並 qWarning。`ProfileLoftSolid::baseShape()` 保存未開孔實體供 Chamfer 使用。

## 連動
- 安裝位置被編輯／組件增減 → `Document::applyComponentChange()` / `syncSlabPlan()` → `rebuildLoftsForComponents()`（Chamfer 連 Loft 的 shapeChanged 自動跟著重建）。
- 斷面陣列重建 → ComponentInstall 重算放置後的組件（`refreshSources()`，合併多次請求）。
- 組件資料以 BRep（base64）內嵌在文件 JSON，不依賴來源檔是否還在。

## 使用者介面
- Railway 選單 / 指令 `insertcomp`（別名 `icomp`）：選 *.aicad → 指定每個實體角色（組件／所需空間／略過）→ 輸入安裝位置。
- Feature Browser 的組件項目（root 下）右鍵：「編輯安裝位置…」、聚焦、隱藏。

## 階段
- **階段 1（本次，已實作、尚未編譯／實測）**：插入、角色指定、多位置安裝、cant 定位、道版 Loft／Chamfer 開孔、編輯位置、存檔／讀檔。
- 階段 2（建議）：以實際 *.aicad 驗證座標軸慣例與方向；所需空間的半透明顯示；開孔效能（大量位置時）；
  位置的「里程範圍／等間距」批次輸入；組件旋轉（偏航角）、高度偏移；以軌道面曲面（而非線性內插）取 A(p)。
- 階段 3（可選）：組件庫（多個組件、重複使用）、與道版 E,N 平面圖／DXF 輸出連動（開孔輪廓出圖）。

## 已知風險
- 全部尚未編譯；布林運算對複雜／非流形的所需空間可能失敗。
- 里程不在任何陣列測站範圍內 → 該位置不顯示、不開孔（組件項目顯示錯誤狀態並列出原因）。
- 目前 Loft 開孔採整個 Loft 一次布林；位置很多時重建會變慢。

## 第 25 項：組件座標線（與草圖約束）、獨立管理項目、與來源檔同步

### 組件座標線 = 主草圖中的參考幾何
組件的「原點／軸線／平面」以兩條 **Centerline 角色**的線畫在斷面主草圖中（`ComponentInstall::createFrameInSketch`）：
- **X 軸線**：起點 = 組件原點，方向 = 組件 +X（亦即 XZ 平面在斷面平面上的跡線）。
- **Y 軸線**：與 X 軸線共用起點（共用原點），方向 = 組件 +Y（YZ 平面的跡線）。
- Z 軸恆為沿線方向（= 斷面平面法線），所以 XY 平面恆平行於斷面平面；沿線偏移由「安裝里程」決定。

它們就是一般草圖幾何，可用草圖所有約束與草圖的軸線／原點／建構線（包含 cant 直線）互相約束；尺寸運算式可直接用 `cant`。
預設約束：原點與 cant 直線起點重合、X 軸線 ∥ cant 直線、X ⟂ Y —— 組件預設貼在軌道面上、隨超高轉動。
Centerline 角色不進入輪廓（不影響 Loft），且 cant 直線辨識會略過 Centerline（`locateCantLine`），不會被誤認。

### 定位
對每個安裝里程取兩個相鄰測站「求解後」的 X 軸線（`SketchInstance::solvedLineEnds`，不需建立檢視草圖），
原點與方向依里程內插 → 放到 `AlignedProfileArray::frameAt(p)` 的精確座標系中。沒有座標線時退回貼 cant 直線的預設。
因為座標線是草圖的一部分，**安裝的位置與轉角隨每個測站的 cant 自動變化**；改草圖約束 → 陣列重建 → Loft 重新開孔，全自動。

### 管理項目
組件集是 Feature Browser root 下獨立的一個項目：eyeOpen／eyeClose、「編輯安裝位置…」、
「建立／重設組件座標線…」、「同步來源檔」、「切換自動同步」、聚焦、隱藏。

### 與來源 *.aicad 同步
- 內嵌 BRep 副本 + 來源路徑 + 上次同步時的檔案修改時間 + 來源實體 id／名稱（同步時優先以 id 對應角色）。
- `QFileSystemWatcher` 監看來源檔：存檔 → 自動同步 → 重算組件並讓所有 Loft 重新開孔（預設開啟，可切換；處理「刪除再建立」式存檔會讓監看失效的情況）。
- 讀檔時若來源檔比內嵌副本新 → 自動同步一次（文件標記為已修改）。
- 手動：右鍵「同步來源檔」。

### 尚未做 / 限制
- 約束解決目前以「座標線在各測站求解後的位置」為準；Y 軸線只參與草圖約束，定位時 Y 由 Z × X 導出（鏡像的 Y 約束不會翻轉組件）。
- 沿線偏移目前只有「安裝里程」；若要相對座標線再偏移沿線距離，需另加欄位。
- 各測站間座標線位置以線性內插；測站密（1.5～3 m）時誤差可忽略。

## 第 26～28 項

### 26. 組件定義 ↔ 安裝位置分離
- **插入組件（INSERTCOMP）**：載入 *.aicad → 指定實體角色 → **選擇要與哪一個 Sketch 建立約束關係**
  （預設 = 作用中草圖 → Feature Browser 目前選取的 Sketch → 第一個斷面陣列的主草圖；也可選「不建立約束」）。
  座標線建在所選草圖；該草圖沒有 cant 直線時座標線建在草圖原點、只加 X⟂Y，請自行加約束。
  插入時**不再**輸入安裝位置。
- **組件安裝位置（新功能）**：Feature Browser 新增 root 項目「組件安裝位置」（虛擬資料夾，底下列出各組件）：
  雙擊或右鍵「新增／編輯各組件安裝位置…」→ 一張表，每列 = 組件 + 線路 + 里程 + 橫向偏移 + 旋轉 180°，
  可跨組件新增／複製／刪除；確定後各組件重算、所有 Loft 只重建一次並重新開孔。
  資料夾右鍵也可「插入 3D 組件…」；資料夾的 eye 一次切換所有組件。
- 尚未指定位置的組件不算錯誤（只是不顯示）。

### 27. 雙擊組件 → 另一個 CADView 編輯
雙擊組件項目（或右鍵「在另一個 CADView 編輯組件」）→ `DocumentManager::openDocument(sourcePath)`
（已開啟的同一檔案會重用）。來源檔存檔後，本文件的組件透過 QFileSystemWatcher 自動同步並重新開孔（見第 25 項）。

### 28. Extrude 方向／尺寸編輯
Extrude 右鍵「編輯擠出（方向／尺寸）…」：高度（可用參數運算式）、方向（正向／反向／對稱）、
**反向附加長度**（新增，沿反方向再延伸 → 非對稱兩側擠出；總長 = 高度 + 反向附加長度）。
一次套用只觸發一次重建（`Extrude::setParameters`）。

## 第 29 項：組件座標系慣例（取代先前的 X 右／Y 上／Z 後）
斷面草圖在 XY 平面（其 Z 軸 = -T，T 為里程增加方向）。組件局部座標系：
- 原點：該里程中心線上、軌道面（cant 直線）的點
- **+X**：與 cant 直線貼合，朝右手邊鋼軌
- **+Y**：與草圖 **-Z** 貼合（= 沿線、里程增加方向 T）
- **+Z**：X × Y，垂直軌道面朝上（一般 CAD「Z 向上」的建模習慣）

定位矩陣 = [ X = D(p)，Y = -Z_frame，Z = X × Y ]；「旋轉 180°」= 繞軌道面法線（Z）轉 180°（X、Y 同時反向，Z 不變）。
組件座標線（草圖中）改為 **X 軸線 + Z 軸線**（Z 軸線 = X 軸線逆時針 +90°，垂直軌道面）；
+Y 垂直於草圖平面，畫不進 2D 草圖，由定位自動給定。XZ 平面恆平行於斷面平面。
所需空間沿線方向的範圍改取組件局部 Y 的延伸。舊檔 JSON 的 `frameYLine` 欄位會被當作 `frameZLine` 讀入。
⚠️ 已用舊慣例（Y 上、Z 後）建模並安裝的組件，轉到新慣例後方向會不同，需要重新確認。

## 第 29 項（另一個）：CADView 頁籤切換
目前 UI 只有「一個共用的 CadView」；開啟第二個文件（例如雙擊組件開來源 *.aicad）會把這個 CadView 改綁到新文件，
先前沒有任何方式切回原文件。新增 `DocumentTabBar`（中央區域 = 頁籤列 + CadView）：
- 每個開啟的文件一個頁籤（標題 = 檔名，未儲存加 ` *`；tooltip = 完整路徑）；只有一個文件時頁籤自動隱藏。
- 點頁籤 → 存下目前視角到文件 → `DocumentManager::setCurrentDocument` → 以「開啟檔案」同一條流程
  （`DOCUMENT_OPENED`）重新綁定 CadView、還原視角；手動發 `allFeaturesLoaded` 讓線形 renderers 依該文件重建；
  Railway 彙總 3D 顯示依該文件重新顯示。
- 草圖編輯／指令進行中不允許切換（提示後還原頁籤選取）。
- 關閉頁籤：有未儲存變更時詢問（存檔／捨棄／取消）；至少保留一個文件。
限制：仍是「一個 CadView 輪流綁不同文件」，不是每個文件各自一個 CadView 實體；各文件的 per-document UI 狀態
（線形 overlay、vAlign dock…）靠切換時重建，沒有各自保留。

## 第 30、31 項
### 30. 定義平面（DefinedPlane）
- 平面 = **基準平面 + 沿其法向量的有號偏移量**（可用參數運算式）。基準可為 XY／XZ／YZ（注意 XZ 的法向量為 -Y）
  或另一個 DefinedPlane（可串接，擋循環）。例：基準 XY、偏移 `-90` → z = -90（往 -Z 方向 90 單位）。
- Feature Browser 的獨立項目（root 下，ItemType::DefinedPlane），3D 視圖中為半透明方形；存檔／讀檔保留（讀檔依檔案順序重建）。
- 建立：指令 `defplane`（別名 `dplane`；選單 Sketch ▸ Define Plane…）；或在 XY／XZ／YZ 項目右鍵「以此平面定義新平面（偏移）…」。
- 使用為草圖平面：項目右鍵「在此平面建立草圖」；或 Create Sketch 互動選平面時，直接在 Feature Browser 點選這個平面項目。
- 右鍵「編輯平面（基準／偏移）…」（`Document::updateDefinedPlane`）；已建立的草圖不跟著移動。
- 限制：Create Sketch 選平面時尚不支援在 3D 視圖中直接點選定義平面（可用樹狀圖點選）。

### 31. Extrude 值與方向
「編輯擠出」對話框改為四種模式：單向（正向）、單向（反向）、兩向平分（給總長，兩側各半）、
兩向各自給值（第一側＝法線正向、第二側＝反向，各自一個值）；所有值可用數字或參數運算式。
屬性面板顯示目前的方向／兩向資訊（唯讀），「高度」仍可直接在面板修改。

## 第 33～36 項
### 33. 單位（mm → m）與安裝里程的精確超高
- 組件（*.aicad）與 Sketch 預設單位 mm、世界座標為 m：放到安裝位置時先縮小 1000 倍
  （`ComponentInstall::unitScale()`，預設 0.001，存檔；定位變換 = 旋轉平移 ∘ 縮放）。所需空間（void）同樣縮放，開孔範圍的沿線餘量也換成 m。
- 安裝位置的超高：不再在相鄰兩測站之間內插，而是在**安裝里程**建立一個「探針測站」
  （`AlignedProfileArray::createProbeAt(p)`，用該里程精確的 cant／H 與各測站相同的 stationParameters 解算主草圖，不加入文件），
  從探針讀組件座標線（或 cant 直線）→ 組件才會落在該里程正確的軌道面上。

### 34. 組件 = 檔案內所有 3D 特徵的組合結果
> **第 37 項已取代「以名稱 void 區分」的規則：改由 Feature Browser 固定根節點 Void／Assembly 的歸屬決定（舊檔仍以名稱遷移）。**

不再逐一指定角色。`ComponentInstall::extractFromDocument()`：
- 名稱為 **void**（不分大小寫；void、void1、void_2…）的 3D 特徵 → 合成「void」（道版 Loft 開孔／差集的空間，不一定要有）。
- 其餘所有 3D 特徵（只取終端結果，被其他特徵消耗的中間實體不重複）→ 合成「組件實體」（顯示在安裝位置）。
- 同步來源檔使用同一規則。void 內各實體分開當布林工具（避免同一 compound 內互相重疊使布林失敗）。

### 35. 道版兩端的端面邊緣倒角
- `ProfileArraySegment` 新增 `endChamfer`（預設 true）、`endChamferSize`（預設 0.025 m，兩個距離相同）；舊檔缺欄位 → 預設要倒角。
- 分段資料表新增兩欄「端部倒角 Chamfer（是／否）」「倒角尺寸 [m]」（可貼上；新增列沿用上一列設定）。
- `ProfileLoftSolid::applyEndChamfer()`：找出本段頭、尾測站位置上的平面端面，倒角其邊緣；**底邊（面內外向 Z 分量 < -0.3，含底部 45° 小倒角）不倒**。
  順序：放樣 →（Chamfer 特徵的縱向倒角）→ 端部倒角 → void 開孔。倒角失敗時維持未倒角並警告。

### 36. 組件與草圖對位預覽
eyeOpen「組件所約束的 Sketch」時，一併 3D 顯示組件（半透明橘）與 void（半透明紅）「對上的情形」：
依主草圖中組件座標線目前的解，放在草圖所在位置、草圖單位（mm，不縮放）（`ComponentInstall::sketchPreview`）。
UIManager 以 300 ms 定時簽章同步（草圖可見性、座標線位置、組件資料變了就更新），草圖隱藏即移除。

## 第 37 項：Part／Assembly／Void 固定根節點（取代以名稱 void 區分）

每個文件的 Feature Browser 永遠有三個固定根節點（順序：Part、Assembly、Void）：

| 根節點 | 意義 | 底下的內容 |
|---|---|---|
| **Part** | **造型**：單一零件的本體 | 擠出、倒角實體等造型特徵（新建的擠出預設放這裡） |
| **Assembly** | **組合**：由零件組成 | 以 INSERTPART 插入的零件檔（`*.aipart`／`*.aiasm`）與「配合 Mates」資料夾；也可以放造型特徵 |
| **Void** | **開孔**：道版 Loft 在安裝位置要挖除的空間，不一定要有 | 組成開孔形體的特徵或插入的零件檔 |

- **組件**（沿線形安裝的實體）＝ Part ∪ Assembly 的終端結果；**開孔** ＝ Void。`ComponentInstall::extractFromDocument()` 以 `Feature::isVoid()` 區分，組件為空時回報「Part／Assembly 底下沒有 3D 組件實體」。
- 歸屬存在特徵的 `group`（`part`／`assembly`／`void`，`groupVer` = 2）。**舊檔相容**：沒有欄位 → 名稱為 void、void1、void_2… 者為 Void；上一版（只有 Void／Assembly 兩個根）的 `assembly`，造型特徵改放 Part、零件留在 Assembly。
- 能放在根底下的特徵：`Extrude`、`ChamferSolid`、`AssemblyPart`（`Document::isGroupable`）。擠出底下的草圖等「有父特徵」者仍掛在父特徵下。
- **搬移特徵的三種方式**：① **拖放**：把特徵拖到 Part／Assembly／Void 根（或其底下的項目）；② 特徵右鍵「移到 …」；③ **新建時直接決定**（見下）。互相消耗的特徵（倒角消耗擠出）一併移動，不會讓中間實體與最終實體分屬兩個根。
- **新建擠出時直接決定放進哪個根**：文件有「目前放置根」（樹狀圖中以 `◀` 標示）。預設依文件種類（零件文件 → Part、組合文件 → Assembly、專案 → Part）；根節點右鍵「設為新增特徵的放置位置」可改。EXTRUDE 的提示列另有可點選的 `[Part(P)/Assembly(A)/Void(V)]`，點選會**立即**把正在建立的擠出移到該根（Void 以半透明紅色顯示），並同時成為「目前放置根」。倒角沿用來源實體的根。
- 顯示：Void 底下的特徵以半透明紅色顯示；三個根的眼睛圖示一次切換底下全部特徵。

## 第 38 項：檔案種類與副檔名

三種檔案以副檔名區分，種類也寫在檔內（`docKind`），舊檔沒有該欄位時依副檔名推斷：

| 種類 | 副檔名 | 內容 | 用途 |
|---|---|---|---|
| 專案 | `.aicad` | 完整專案：線形、草圖、道版、圖紙… | 一般設計文件（沿用） |
| 零件 | `.aipart` | 單一零件，造型特徵在 Part 根 | INSERTPART 插入組合；也可 INSERTCOMP 直接安裝 |
| 組合 | `.aiasm` | 由零件檔插入＋配合組成（Assembly 根），可含 Void | **INSERTCOMP 沿線形安裝的組件**；也可當子組合插入組合 |

- 檔案選單：`New Project`（Ctrl+N）、`New Part`（`NEWPART`）、`New Assembly`（`NEWASM`）。新文件的種類決定預設副檔名與「目前放置根」。
- 開啟：一次列出三種；另存新檔：該種類的格式排第一，沒輸入副檔名時自動補上；以不同副檔名另存即轉換種類。INSERTPART 篩選 `*.aipart *.aiasm`、INSERTCOMP 篩選 `*.aiasm *.aipart`；舊版 `*.aicad` 仍可選用。三種檔案的內容格式相同（JSON），舊程式／舊檔不受影響。

## 第 39 項：沿線形安裝時如何使用 Assembly 與 Void 的內容

來源檔（`.aiasm`／`.aipart`／舊版 `.aicad`）在插入組件時拆成兩份內嵌副本：**組件**（Part ∪ Assembly）與 **開孔**（Void）。每個「安裝位置」（線路、里程、橫向偏移、旋轉 180°）各自有兩個開關：

| 開關 | 預設 | 作用 |
|---|---|---|
| **安裝組件** `installAssembly` | 開 | 在此里程放置組件實體（Part＋Assembly 的終端結果），依該里程的超高定位 |
| **開孔** `cutVoid` | 開 | 在此里程用 Void 對涵蓋它的道版 Loft 做差集開孔 |

- 兩者可分開使用：例如只開孔不放組件（預留孔位）、或只放組件不開孔（組件在道版外）。
- 舊檔沒有這兩個欄位 → 都開，行為與以前一致。位置表（INSERTCOMP 與「組件安裝位置」編輯）各多兩個勾選欄。
- 組件來源檔中的組合（含配合）已解好、位姿存在檔內；沿線形安裝時整個組件視為一個剛體，不會重新求解。來源檔存檔後自動（或手動）同步，位置與開關保留。
- 目前開孔只作用在道版 Loft；對其他實體開孔列為後續。
